# The Republic of PC Gamers

A polished static front-end concept for a PC hardware discovery + PC builder platform.

## Run
Open `index.html` in a browser, or serve the folder with any static server.

## Pages
- `index.html` — login / entry
- `home.html` — Republic HQ
- `builder.html` — interactive PC builder
- `parts.html` — searchable hardware armory
- `about.html` — project information

## Notes
- Login buttons are functional demo UI. Real Google/Facebook/Apple OAuth requires an OAuth backend and credentials.
- Component images use remote image URLs for the prototype. Replace them with licensed manufacturer/product images for a production site.
- FPS figures are illustrative estimates, not benchmark results.
- The component catalog is intentionally data-driven: add more objects to `data.js` to expand the archive across old, current and future hardware.
